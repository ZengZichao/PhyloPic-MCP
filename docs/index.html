Overview

This MCP server wraps the PhyloPic API v2 as a set of MCP tools, enabling AI assistants such as Claude to:

  • Search for taxa 鈥?find phylogenetic nodes by scientific name (e.g., "Primates", "Homo sapiens", "Aves")
  • Retrieve silhouette images 鈥?get detailed image information including download links at various resolutions
  • Browse contributors 鈥?list all image contributors and their contribution statistics
  • Resolve external identifiers 鈥?convert IDs from GBIF, NCBI, Open Tree of Life, etc. to PhyloPic nodes
  • View taxonomic lineages 鈥?get the ancestral lineage chain for any node
  • Check API status 鈥?verify PhyloPic API availability

Installation

Prerequisites

  • Node.js ≥ 18.0.0
  • npm or another package manager

Install from Source

# Clone the repository
git clone https://github.com/ZengZichao/phylopic-mcp.git
cd phylopic-mcp

# Install dependencies
npm install

# Build TypeScript
npm run build

The compiled files will be in the dist/ directory.

Configuration

Using with Claude Desktop

Add the PhyloPic MCP server to your Claude Desktop configuration file:

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json 

{
  "mcpServers": {
    "phylopic": {
      "command": "node",
      "args": [
        "C:\\path\\to\\phylopic-mcp\\dist\\index.js"
      ]
    }
  }
}
Replace the path with the actual absolute path to your dist/index.js.

Using with Other MCP Clients

This server uses the standard stdio transport protocol and is compatible with any MCP-supporting client. The launch command is: 

node /path/to/phylopic-mcp/dist/index.js

Debugging with MCP Inspector

npm run inspector

This will launch the MCP Inspector web interface for interactive testing.

Available Tools

This server provides 16 MCP tools:

01 search_taxa
Search for phylogenetic nodes by scientific name. query (string, required), page (number, optional).
02 autocomplete_taxa
Get taxonomic name suggestions based on partial text. query (string, required).
03 get_node
Get detailed information about a phylogenetic node by UUID. uuid (required), optional embeds: embed_parentNode, embed_primaryImage.
04 get_node_lineage
Get the ancestral lineage chain for a given node. uuid (required).
05 get_root_node
Get the root phylogenetic node (common ancestor of all organisms). Optional: embed_primaryImage.
06 get_image
Get detailed image information including download links. uuid (required), optional embeds: embed_contributor, embed_generalNode, embed_specificNode, embed_nodes.
07 search_images_by_node
List images that directly represent a specific node. node_uuid (required), page (optional).
08 search_images_by_clade
List images within a clade (node and all descendants). clade_uuid (required), page (optional).
09 list_images_by_contributor
List all images uploaded by a specific contributor. contributor_uuid (required), page (optional).
10 list_contributors
List all contributors, sorted by image count. page (optional).
11 get_contributor
Get detailed contributor information by UUID. uuid (required).
12 list_licenses
List all Creative Commons licenses for image submissions. No parameters.
13 list_namespaces
List authorized external taxonomic database namespaces. No parameters.
14 resolve_external_id
Resolve an external database identifier to a PhyloPic node. authority, namespace, object_id (all required).
15 get_api_info
Get API general information: version, build number, endpoints. No parameters.
16 ping
Check if the PhyloPic API is operational. No parameters.

Usage Examples

Scenario 1 鈥?Find a Silhouette of an Organism

  1. Use autocomplete_taxa with "dro" 鈫?discover "drosophila"
  2. Use search_taxa to search "drosophila" 鈫?get the node UUID
  3. Use search_images_by_node with the node UUID 鈫?get the image list
  4. Use get_image to get specific image download links

Scenario 2 鈥?Find All Images of a Class

  1. Use search_taxa to search "aves" (birds) 鈫?get the node UUID
  2. Use search_images_by_clade with the node UUID 鈫?get all bird images

Scenario 3 鈥?Look Up by NCBI Taxon ID

  1. Use list_namespaces to see available databases
  2. Use resolve_external_id with authority="ncbi.nlm.nih.gov", namespace="taxid", object_id="9443" (Primates)
  3. Use the returned node UUID to further query images

Technical Notes

PhyloPic API Build Numbers

The PhyloPic API uses a build number system. Each API request must include the current build number; otherwise a 307 Temporary Redirect is returned. This server's API client automatically handles build numbers:

  1. On the first request, it fetches the current build number from the API root endpoint
  2. Subsequent requests reuse the cached build number
  3. If a 410 Gone response is received (stale build), it automatically re-fetches and retries
